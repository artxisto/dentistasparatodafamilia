# Dentistas para Toda Família — Landing page

Protótipo de landing page da clínica odontológica do Dr. Cássio Antônio Xisto, no Centro de Cáceres-MT.

- `index.html` — página única (HTML + CSS inline, ícones em SVG)
- `assets/dr.jpg` — foto do Dr. Cássio

Para ver: abra o `index.html` no navegador ou ative o GitHub Pages (Settings → Pages → branch `main`, pasta `/`).

Pendências: número do CRO-MT, formas de pagamento e frase do Dr. Cássio.
